Installation

Cross the event horizon.

One command clones the repo, configures the environment, builds five Docker services and opens the interface. Idempotent: run it again anytime to update.

0

Before you start

You need Docker Desktop (or Docker Engine + Compose) running, git, and ~4 GB free for images. macOS, Linux and Windows (WSL2) are supported.

1

Run the installer

Pick your platform. The script asks where your project files should live (default: ~/Documents/AtlasFileProjects) and takes it from there.

curl -fsSL https://raw.githubusercontent.com/aleonnet/atlasfile/main/install.sh | bash
irm https://raw.githubusercontent.com/aleonnet/atlasfile/main/install.ps1 | iex

Optional flags

--dir PATH
install location (default ~/AtlasFile)
--projects-root PATH
where your documents live
--enable-auth
generate an API key and require it
--yes
non-interactive (accept defaults)
4

First steps

The interface opens at localhost:5173 with an onboarding wizard: create your first project, optionally add an OpenAI/Anthropic key for the assistant, then drop files anywhere on the screen.

?

Troubleshooting

“Cannot connect to the Docker daemon”

Docker Desktop isn't running. Start it and re-run the installer — it resumes where it left off.

Port 5173 or 8000 already in use

Another stack is bound to those ports. Stop it, or install to a second instance with --dir and a different name.

How do I update?

Re-run the same one-liner. It pulls the latest main, rebuilds and restarts — your projects and data are preserved.
